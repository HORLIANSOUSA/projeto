# Projeto Aurora

Atividade prática para exercitar **HTML**, **CSS**, **JavaScript** e o fluxo básico do **Git/GitHub**.

## Sobre o projeto

O Projeto Aurora é uma página responsiva de apresentação com:

- HTML semântico;
- CSS em arquivo externo (`css/style.css`);
- JavaScript em arquivo externo (`js/script.js`);
- três imagens SVG na pasta `img`;
- navegação por âncoras e menu mobile;
- botão interativo com mensagem de confirmação.

## Como executar

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` no navegador.

Não é necessário instalar dependências.
